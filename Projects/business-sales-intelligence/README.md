# Business Sales Intelligence Dashboard

AI-powered customer analytics and sales prediction platform built with Python, Streamlit, and scikit-learn.

## Features
- Data cleaning and feature engineering pipeline
- Exploratory data analysis with visualizations
- Customer segmentation (RFM) and product recommendation insights
- Machine learning model to predict repeat purchase likelihood
- Interactive Streamlit dashboard with:
  - Key performance indicators (KPIs)
  - Sales trends
  - Customer analytics
  - Prediction interface
  - Model evaluation and feature importance
